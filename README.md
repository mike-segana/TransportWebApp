# TransportWebApp
TransitFlow

TransitFlow is a full-stack transport operations platform designed to streamline shipment management and transport requests. The application provides secure authentication, shipment tracking, request management, and role-based access control for users and administrators. It was developed to demonstrate modern full-stack software engineering practices, secure authentication, and cloud deployment.

Features
Secure JWT authentication using HTTP-only cookies
User registration and login
Role-based access control (User/Admin)
Create and manage transport requests
View shipment history and current shipment status
Driver assignment and shipment lifecycle management
Responsive dashboard with shipment and request summaries
Cloud-hosted backend and PostgreSQL database
